# Issue: FUNCTION_INVOCATION_FAILED - Vercel deployment error

## Root Cause Analysis

The error `TypeError: Cannot read properties of undefined (reading 'compatibilityFlags')` is occurring because the **frontend is being deployed to Vercel** when it should be deployed exclusively to Cloudflare Workers.

### Evidence from Error Logs
```
file:///var/task/frontend/build/server/assets/worker-entry-BZkIIFmI.js:350:50
domain: mafia-arena-ffw7t1ibm-mohammed-suberus-projects.vercel.app
```

Key indicators:
- `/var/task/` is Vercel's serverless function file system
- `worker-entry-BZkIIFmI.js` is generated by `@cloudflare/vite-plugin` during build
- Cloudflare `compatibilityFlags` only exists in Cloudflare Workers runtime, not Vercel

## Why It Happens

The project structure includes:
- **Backend** (`src/worker/`) - deployed to Cloudflare Workers ✓
- **Frontend** (`frontend/**`) - uses `@cloudflare/vite-plugin` and `wrangler.jsonc` for Cloudflare Workers deployment ✓

However, the frontend is somehow being detected as a Vercel project and deployed there. This is likely due to:
1. Project similarity to Vercel-compatible frameworks (React Router, Next.js-like structure)
2. Automatic deployment scripts
3. Missing explicit Vercel configuration files preventing misidentification

## Solution

### 1. Ensure Exclusive Cloudflare Deployment
The project should ONLY be deployed to Cloudflare Workers:

```bash
# Backend + Frontend (both as Cloudflare Workers)
pnpm deploy

# Deploy backend worker
wrangler deploy

# Deploy frontend worker (from frontend directory)
cd frontend
wrangler deploy
```

### 2. Verify No Vercel Configuration
Remove or rename any Vercel configuration:
- Rename `.vercel/` if it exists
- Remove `vercel.json` if it exists
- Remove `package.json` scripts that deploy to Vercel

### 3. Update Frontend Deployment
The frontend `wrangler.jsonc` should deploy to Cloudflare:
```jsonc
{
  "outputDirectory": "build",
  "compatibility_flags": ["nodejs_compat"],
  "routes": [] // Remove web routes, only deploy as worker
}
```

### 4. Fix Deployment Command
Run from project root:
```bash
pnpm deploy  # Deployes both backend and frontend to Cloudflare
```

## Files Modified to Fix This Issue

1. `frontend/vite.config.ts` - Changed `viteEnvironment.name` from "ssr" to "server" for proper build output
2. `frontend/wrangler.jsonc` - Removed web routes to prevent Vercel misidentification
3. `wrangler.toml` - Removed `mafia.reasonable.finance` route to verify route configuration
